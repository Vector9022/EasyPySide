<h1 align="center">📘 Документация 📘</h1>

* [absPath](absPath.md) - Функция возвращает абсолютный путь к файлу.
* [CFLib](CFLib.md) - Библиотека для работы с файлами конфигурации.
  * [File.Exists](CFLib.md#fileexists--функция-для-проверки-существует-ли-файл-назад) - Функция для проверки существует ли файл.
  * [File.Create](CFLib.md#filecreate--функция-создает-файл-если-ево-нет-назад) - Функция создает файл если ево нет.
  * [File.Delete](CFLib.md#filedelete--функция-удаляет-файл-если-он-есть-назад) - Функция удаляет файл если он есть.
  * [File.Update](CFLib.md#fileupdate--функция-обновляет-содержимое-файла-если-он-есть-назад) - Функция обновляет содержимое файла если он есть.
  * [Params.Set](CFLib.md#paramsset--функция-создает-или-изменяет-значения-параметров-назад) - Функция создает или изменяет значения параметров.
  * [Params.Delete](CFLib.md#paramsdelete--функция-удаляет-параметр-если-он-есть-назад) - Функция удаляет параметр если он есть.
  * [Params.Exists](CFLib.md#fileexists--функция-для-проверки-существует-ли-файл-назад) - Функция для проверки существует ли параметр.
  * [Params.Get](CFLib.md#paramsget--функция-для-получения-параметра-по-ключу-назад) - Функция для получения параметра по ключу.

* [PySideTray](PySideTray.md) - Библиотека для создания значка в системном трее.
  * [DefaultMenu](PySideTray.md#defaultmenu--класс-отвечающий-за-меню-при-взаимодействии-с-значком-назад) - Класс отвечающий за меню при взаимодействии с значком.
    * [setStyleSheet](PySideTray.md#setstylesheet--функция-для-установки-стиля-в-меню-назад) - Функция для установки стиля в меню.
    * [addQAction](PySideTray.md#addqaction--функция-для-добавления-пункта-в-меню-назад) - Функция для добавления пункта в меню.
    * [addCheckableQAction](PySideTray.md#addcheckableqaction--функция-для-добавления-проверяемого-пункта-в-меню-назад) - Функция для добавления проверяемого пункта в меню.
    * [addQActionGroup](PySideTray.md#addqactiongroup--функция-для-добавления-группы-пунктов-в-меню-назад) - Функция для добавления группы пунктов в меню.
    * [addSubMenu](PySideTray.md#addsubmenu--функция-для-добавления-под-меню-назад) - Функция для добавления под меню.
    * [addSeparator](PySideTray.md#addseparator--функция-для-добавления-разделителя-в-меню-назад) - Функция для добавления разделителя в меню.

  * [SystemTrayIcon](PySideTray.md#systemtrayicon--класс-отвечающий-за-создание-и-управление-значком-в-системном-трее-назад) - Класс отвечающий за создание и управление значком в системном трее.
    * [show](PySideTray.md#show--функция-для-отображения-значка-в-системном-трее-назад) - Функция для отображения значка в системном трее.
    * [hide](PySideTray.md#hide--функция-для-скрытия-значка-в-системном-трее-назад) - Функция для скрытия значка в системном трее.
    * [setIcon](PySideTray.md#seticon--функция-для-изменения-иконки-значка-в-системном-трее-назад) - Функция для изменения иконки значка в системном трее.
    * [setToolTip](PySideTray.md#settooltip--функция-для-изменения-всплывающей-подсказки-значка-в-системном-трее-назад) - Функция для изменения всплывающей подсказки значка в системном трее.
    * [showMenu](PySideTray.md#showmenu--функция-для-вызова-меню-назад) - Функция для вызова меню.
