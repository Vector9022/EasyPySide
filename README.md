<h1 align="center">🗂 EasyPySide 🗂</h1>

**Библиотека (набор шаблонов) для быстрого создания графического интерфейса пользователя.**

[[**📘 Документация**](docs/Main.md)]   [[**🔗 Сайт проекта**](https://github.com/Vector9022/EasyPySide)]

## ✨ Возможности
- **Шаблон окна с кастомной строкой заголовка**
- **Множество кастомных виджетов** [В разработке]

## 📦 Установка
```bash
cd localLib
git clone https://github.com/Vector9022/EasyPySide.git EasyPySide_TEMPREPO; `
Move-Item EasyPySide_TEMPREPO\localLib\EasyPySide .; `
Remove-Item -Recurse -Force EasyPySide_TEMPREPO
```
